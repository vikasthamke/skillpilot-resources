How to use a workbook

Most workbooks need a few minutes of setup on your computer. The README in each repository has the exact steps.

  1. Pick a workbook from the list above.
  2. Open its GitHub repository with “Open Workbook”.
  3. Read the README for prerequisites and setup.
  4. Download the whole repository: green Code button → Download ZIP, or git clone it.
  5. Install the dependencies, usually pip install -r requirements.txt.
  6. Open the notebook or follow the project’s instructions.
  7. Start practicing. Try each problem before asking for a hint.

Download the complete repository, not just the notebook. The notebooks import helper Python files and read datasets that live next to them, so a notebook on its own won’t run.
